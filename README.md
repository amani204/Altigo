# Altigo — Landing Page

A modern, bilingual (Arabic/French) landing page for **Altigo**, a new sportswear brand launching with its debut product: performance sport pants.

🔗 Live site: https://altigo-entc.vercel.app/
## Features

- Light / Dark mode
- AR / FR language switch with full RTL support
- Fully responsive design
- Hero section with video/image showcase
- Product gallery
- Product features & brand story section
- "How to Order" step guide
- FAQ accordion
- Order form → sends directly to WhatsApp, pre-filled
- Floating WhatsApp button

## Tech Stack

- React (Vite)
- Tailwind CSS
- GSAP (animations)
- React Hook Form + Zod (form validation)
- Lucide React (icons)

## Getting Started

```bash
git clone https://github.com/amani204/Altigo.git
cd Altigo
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```
